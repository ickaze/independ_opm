# 残る参照由来LFO処理を置き換えるための追加測定

全256周波数設定の収録は完了している。このセットはその再録音ではなく、前回の短い保持区間では誤差が残った波形値・内部丸め・操作応答を対象とする。今回新規に用意した6本で、全て20分未満、PDX不要。

## 録音条件

4 MHz、96 kHz/24bitステレオ、GMC-OPT04の同じ経路。ゲイン固定、EQ・自動音量・ノーマライズ・無音削除なし。左が測定音、右が変調しない基準音。先頭の同期音と末尾無音を残す。ファイルごとの録音を推奨する。

前回より対象と基準のTLを0に上げ、減衰の深い側の測定余裕を増やした。ALG7の単独キャリアで、他のオペレータはTL127。出力がクリップする設定の場合は全ファイル共通のデジタルゲインで下げ、その値を記録する。下げたことを後でノーマライズして隠さない。

|MDX|対象|時間|
|---|---|---:|
|37AMSAW|鋸歯状AM、AMD全128値、AMS1|12分51.949秒|
|38AMSQR|矩形AMの端点、AMD全128値、AMS1|12分51.949秒|
|39AMTRI|三角波AM、AMD全128値、AMS1|12分51.949秒|
|40PMSAW|鋸歯状PM、PMS全8値×PMD境界付近16値、AMD0|12分51.949秒|
|41PMTRI|三角波PM、同上|12分51.949秒|
|42STATE|同値／異値18h、01h保持、波形選択を異なる予定位相で反復|3分39.808秒|

合計約67分59.55秒。先に42STATE・37AMSAW・40PMSAWを送れば、状態と主要な丸め候補を先に調べられる。残り3本は別波形・端点での検証用。各AMD/PMD条件を約6秒観測し、LFRQ80hのゆっくりした保持値を測る。各条件は約1.4周期であり、同条件で2周期完全に比較する設計ではない。別の深度・波形条件を予測検証に使う。

PMはAMを完全に切った状態で測る。前回の深いAM併用時の位相抽出不良を、PMの整数計算式と混同しないため。選択したPMD値は1,2,3,7,15,16,17,31,32,33,63,64,65,95,126,127。全PMD×全波形の総当たりではなく、丸め候補を区別する境界値の測定。

## 波形抽出で必要な変更

今後の解析では元96 kHzデータ上でキャリアの正弦・余弦を局所的に当てはめ、段差から離れた平坦部を読む。12 kHzへの間引き後の瞬時位相だけで深い変調を解釈しない。振幅が量子化床以下に落ちた値は内部値として断定しない。

## MDXだけでは測れないもの

42STATEの時刻はMDXドライバーのtick単位（公称32768マスタークロック）であり、実際のOPMバス書き込みクロックではない。複数の同一tick書き込みにも順序と遅延がある。この録音だけで1クロック単位の状態遷移が必ず決まるとは約束できない。

正確な状態遷移を決めるために追加で必要になる可能性がある記録：

- 実際のOPMクロックを基準としたレジスタ書き込み時刻（アドレスとデータ、実際に受け付けられた順序）。
- リセット解除時刻と01h/18h/1Bh/0Fh操作の時刻。
- 同じ時間軸に対応付けられる音声、可能ならSRC前の音源デジタル出力。
- 再生ソフト名・版、長さ計測上限、音源の初期化方法。

ホストが書き込み要求をキューへ入れた時刻だけでは代用にならない。プレイヤーや接続装置がこの記録を取得できるかは未確認であり、装置に機能があると仮定していない。MDXの公称スケジュールと実バス時刻を区別する。

## 生成・確認

    python generate.py
    python verify.py

生成器はレジスタ列と待ち時間のみを組み立てる。期待する音源波形や他のエミュレータの式は含めない。独立デコードで予定表・レジスタ列・終端・無限ループがないことを確認した。実機再生はまだ行っていない。

この測定が成功してもライセンスが自動的に変わるわけではない。測定仕様から新規実装し、参照由来コード・テストが残っていないかを確認する工程が別に必要。
