# 周期LFO実機録音の検証報告

2026-09-14。対象：13〜36の24本のFLAC。設定4 MHz、96 kHz/24bit、ステレオ。

## 結論

全24ファイルについて収録範囲を調べ、得られる周期・波形・深度・操作応答を検証した。高速側128設定の平均周期、低速側の段差間隔、感度による変調量、保持操作とAMEの有効範囲を測定できた。

しかし、**今回だけでX68Sound参照範囲の全てを確定仕様として置き換え、CC0化できる状態には至っていない。** 25番の測定音欠落と26番の途中終了があり、内部の端点・丸め・書き込み直後の全状態遷移も一意に確定していない。実装・ライセンスは今回変更していない。

## 1. 入力の確認と欠落

全入力は96 kHz、2ch、24bitとして報告されるFLAC。入力の長さ・サイズ・SHA-256はinputs.jsonに保存した。圧縮形式を理由に精度を落として解析したわけではない。ただし測定処理では後述の帯域制限と間引きを行っている。

|ファイル|実際の長さ|MDX予定長|結果|
|---|---:|---:|---|
|takes/initial/25F00.flac|13.526秒|2883.387秒|測定音なし。抽出振幅の最大は約1.99×10^-7 FSで、基準音も検出できない|
|26F10.flac|1200.033秒|1443.430秒|10h〜1Chは全区間、1Dhは途中まで。1Eh・1Fhは未収録|
|その他22本|recording_coverage.csv参照|同表参照|予定の測定音区間を検出。32・36には長めの末尾余白がある|

全256周波数設定のうち237設定を区間全体で観測した。00h〜0Fhの16設定と1Dh〜1Fhの3設定、合計19設定は完全区間がない。1Dhの一部を完全な検証済み区間には数えていない。

**25・26の元録音を確認し、正しい全長ファイルがあれば、その2本だけ再送すればよい。** 元データにも欠落がある場合は25F00と26F10を再録音する。ほかの22本を再録音する必要があるとは現時点では判断していない。

## 2. 高速側のタイミング

17〜24から80h〜FFhの128設定について鋸歯状AMの折り返し周期を測った。波形を生成する既存ソースを期待値に使わず、録音の周期性と段差列を検出した。

レジスタ上位桁をH、下位桁をLとしたとき、録音上の平均周期は次の実測近似で説明できる。

    T[s] = 2^(15−H) / (30.5196670 + 1.90771074 × L)

これは今回の録音時間軸で得た係数であり、チップの正確な物理クロックや整数分周器の定義ではない。

|測定|結果|
|---|---:|
|係数推定に使用|下位桁が偶数の64設定|
|係数を固定した検証|下位桁が奇数の64設定|
|検証側の周期相対RMS誤差|0.044678%|
|検証側の最大相対誤差|0.192319%|

80hは約4.194秒、90hは約2.0968秒、A0hは約1.0485秒、B0hは約0.52423秒。下位桁を増やすと平均周波数がほぼ直線的に増える。

タイミング誤差には1 msの抽出格子、折り返しが複数の内部段階にまたがること、録音と書き込み時刻のずれが含まれる。全設定で内部カウンタの更新位置や小数持ち越し列が一致したという検証ではない。

初回のdB微分による検出は、高速設定で補間の振れを別の段差と誤認した。振幅の周期性と十分な最小間隔を用いた検出へ変更した。frequency.jsonは初期集計、frequency_refined.jsonとfrequency_law.jsonが改善後の結果である。

## 3. 低速側の段差間隔

完全区間がある設定での、上位桁ごとの段差間隔の中央値：

|上位桁|段差間隔の中央値|
|---|---:|
|1|2.097秒（10h〜1Ch）|
|2|1.048秒|
|3|0.524秒|
|4|0.262秒|
|5|0.131秒|
|6|0.066秒|
|7|0.033秒|

上位桁を1増やすと間隔が約半分になる観測を得た。ここでは波形一周の周期ではなく段差間隔を示している。下位桁による進み幅の増減を、内部の小数アキュムレータと全クロック一致で同定したとは扱わない。

## 4. AM深度

15番のAMD全128×AMS全4＝512条件とAME無効対照を確認した。矩形波の安定した高低値を比較し、遷移時のオーバーシュートの影響を減らすため四分位値から変調幅を求めた。

- AMS0ではAMDを変更しても変調幅は約0.001 dB程度の抽出揺らぎに留まる。
- AMS1/2/3で変調量が増える。深い条件では低振幅側がノイズ床に近づき、測定値が飽和する。
- 安定して観測できる範囲で偶数AMDから直線を推定し、奇数AMDを予測した結果は次の通り。

|AMS|使用AMD範囲|傾き dB/AMD|切片 dB|奇数側RMS誤差|
|---|---|---:|---:|---:|
|1|1〜110|0.188376|−0.097674|0.001974 dB|
|2|1〜110|0.378458|−0.244785|0.036184 dB|
|3|1〜60|0.758587|−0.468564|0.061465 dB|

この直線を内部整数式として採用することはしない。振幅の非線形性、量子化、抽出方法が含まれる。また深いAMS3で観測された約74 dBの上限をLFOの仕様上の上限と解釈してはいけない。

## 6. 波形、保持、チャンネル

14番では2音域×3波形×AM/PM/併用の18区間、36番では48区間を測定した。A0hでのAM・PMの周期はいずれも約1.048秒。前半から作った128分割の経験的波形で後半を予測したところ、三角波AMのRMSは約0.046 dBだった。一方、鋸歯状・矩形波の段差を含めると約0.77〜1.22 dBが残る。これは内部波形テーブルが完全復元できたという結果ではない。

36番の一部低速区間は、前半だけでは学習に必要な周期数が足りない。waveform_fits.jsonのstatusがinsufficient training cyclesの結果は検証成功として数えない。

33番では01h bit1の保持中、3波形ともAMD80の減衰量が約14.97 dBでほぼ一定となった。AMDだけの変更でAMが変わり、PMDだけの変更でPMが変わる挙動も観測された。ただし、同値18h書き込みとキー操作をまたいだ位相を1クロック単位で確定したものではない。キーオフ中の位相推定値は意味を持たないため、仕様値として使用しない。

34番の全8ch×4スロットで、AME無効後のAM幅は最大約0.00475 dBまで低下し、PMの変化は残った。対象以外をTL127にしたため、数学的な無音を仮定せず残留成分を含む測定として扱った。

## 7. 併用条件で失敗した推定

14番の経験的波形を15/16番の矩形深度比で単純に拡大縮小し、35番の前半で位相だけを合わせ、後半を予測した。

- AM：区間RMSの中央値0.253 dB、最大5.610 dB。
- PM：低振幅点を除いた後でも中央値1.558 cent、最大470.296 cent。

特に深いAMを伴う条件では、振幅が大きく変わる音から瞬時位相を取り出す方法自体に誤差が生じる。低振幅点を除外するだけでは解消しなかった。従ってこの不一致を「実機のAMとPMは独立でない」という証明にも、「実装すべき特殊な補正係数」にも使わない。

単純な倍率変換と今回の抽出法だけでは、全条件の置換根拠として不十分だったことを記録する。joint_prediction.jsonに除外率を含めて保存した。

## 8. 置き換えに使える範囲と残る作業

現時点で使える一次測定は、高速側全設定の平均周期、低速側の観測済み段差間隔、感度と有効ビットの作用、安定条件での変調幅、3波形の概形と周期である。

次の項目は未確定として残す。

1. 未収録19設定、とくに00h〜0Fh。
2. 波形の全端点と内部整数値、深度計算の丸め位置。
3. 小数カウンタの全更新列、レジスタ書き込み直後の状態。
4. 深いAMを伴うPMの信頼できる抽出と、別条件での予測。

録音と一致したという事実だけで参照由来ソースの権利が消えるわけではない。測定仕様に基づく新規実装、参照由来テストを含めた残存範囲の確認を経てからライセンスを検討する。今回の報告はCC0適用可否の法的確定ではない。

## 再実行と同梱物

Python 3、NumPy、SciPy、Matplotlib、ffmpeg/ffprobeを使用。

    python periodic-analysis/extract.py
    python periodic-analysis/analyze.py
    python periodic-analysis/refine.py
    python periodic-analysis/depth_fit.py
    python periodic-analysis/wavefit.py
    python periodic-analysis/joint_check.py
    python periodic-analysis/make_report.py

ZIPを展開した最上位を作業ディレクトリとし、元の名前のFLAC24本をupload/に配置する。lfo-independent-testsには今回使用した区間表とMDX生成・検証コードを同梱している。元FLACと中間NPZは容量のため本報告に重複同梱しない。数値表、解析コード、入力ハッシュ、図を同梱した。

抽出は12 kHzへ帯域制限した音声から解析信号を求め、振幅・瞬時周波数を1 kHzで保存している。20秒ごとのブロックに前後0.25秒の余白を取り、区間端を解析から除外した。内部の1クロックや高速段差の厳密な位置をこの抽出だけで判定することはできない。

公称MDX時刻には各録音の基準音区間から線形の位置合わせを施した。そのため、公称時刻との一致を独立したタイミング検証には数えない。計算・検出に失敗した初期結果と、改善後の結果を区別して保存している。
