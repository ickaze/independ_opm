## 新たな観測

00h〜05hでは段差間隔の中央値が約4.194秒、10h〜1Fhでは約2.097秒だった。下位桁が変わってもこの基本間隔はほぼ一定で、1段分と2段分の変化の出現率が変わった。

観測された小さい方の減衰量変化の中央値は約0.09445 dB。これを内部の厳密な1単位と断定せず、変化量を大小に分類するための実測しきい値として使用した。しきい値はその1.5倍。全録音からしきい値を求めているため、完全な盲検試験ではない。

各完全区間で42回の変化を抽出した。完全区間22個（25番の6個、26A/Bの16個）に対し、以下の候補を比較した。

### 候補A：単純な小数加算

下位桁をL、位相をpとして、n回目の追加1段の有無を

    floor((p+(n+1)*L)/16) - floor((p+n*L)/16)

で表す。p=0..15を先頭16回で選択した。

- 先頭16回×22区間の不一致：44回。
- 続く26回×22区間＝572回の不一致：68回。

平均の進み方が似ていても、この候補だけでは今回観測した追加段の配列を説明できない。

### 候補B：4ビット反転カウンタの比較

    reverse4(x) = xの下位4ビットの並びを反転
    extra[n] = reverse4((p+n) mod 16) < L
    increment[n] = 1 + extra[n]

同じくp=0..15を先頭16回だけで選択した。

- 先頭16回×22区間の不一致：0回。
- 位相を固定した後の572回の不一致：0回。

例えばL=3では、追加段の出現が均等な5/5/6間隔にならず、4/4/8型の間隔となる。平均速度だけの検証では分からなかった差を確認できた。

候補Bは今回の定常状態の観測を説明する等価モデルであり、物理的な内部カウンタがそのまま存在すると証明したわけではない。また、候補Bは今回の観測を見て選んだものであり、候補選択まで含めた事前登録型の検証ではない。

## 残りだけを録音するMDX

remaining-mdx/mdx 内の3本を用意した。既に全区間がある00h〜05hと26A/Bの再録音は不要。

各設定の観測時間は元の25番と同じ約180秒。4 MHz、96 kHz/24bit、ステレオ、同じ固定ゲインで録音する。先頭同期音と末尾無音を残す。全ファイル20分未満で、繰り返しなし。MDXを独立デコードし、待ち時間・レジスタ列・予定表・終端が一致することを確認済み。実機再生は未確認。

## 再実行

ZIP最上位にて実行。元の3本のFLACを recovered/ に置く。

    python periodic-supplement/extract.py
    python periodic-supplement/analyze.py
    python periodic-supplement/carry_check.py
    python periodic-supplement/bit_reverse_check.py

抽出にはffmpeg/ffprobe、NumPy、SciPyが必要。results.jsonには抽出した全段差時刻・変化量を保存したので、最後の2つの候補比較は元音声なしでも再計算できる。追加MDXの再生成には同梱のlfo-independent-tests/mdx_writer.pyを使用する。
