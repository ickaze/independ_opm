# 周期LFO 独立実装用 実機測定セット v1

目的は、現在のLFOのタイミング・波形値・深度処理・レジスタ状態遷移を、録音から得た仕様に基づいて新規実装するための証拠を集めることです。このセット自体はエミュレータを使わず、OPMレジスタ書き込みと待ち時間だけでMDXを生成します。PDXは不要です。

## 録音方法

- 前回と同じG.I.M.I.C / GMC-OPT04、YM2151クロック4 MHz、光デジタル96 kHz/24bit、ステレオで録音してください。
- EQ、リミッター、自動音量、ノーマライズ、フェード、無音削除は無効。左右を合成しないでください。録音ゲインは全ファイルで固定してください。
- 最初にprimary.m3uの16本（約51分47秒）を録音してください。その後slow.m3uの8本（約104分11秒）を録音してください。低速側も00h〜FFh全設定の検証には必要です。
- 可能ならMDXごとに同名のWAVにしてください。連続録音でも構いませんが、通常セットと低速セットを分け、順番を記録してください。全部を1本にすると約5.4 GBになり、通常のRIFF WAVのサイズ制限を超えます。
- 各MDXの先頭には同期用の短音3回、末尾には約1秒の無音があります。切り落とさないでください。低速用は途中がほとんど一定音に聞こえても、末尾まで録音してください。
- 演奏速度を変えず、ソフトウェアLFOや追加の音量操作を適用しないでください。プレイヤー名・版、録音ソフト、設定変更があればrecording_notes.txtへ記録してください。
- m3uは再生順の一覧です。プレイヤーが対応しない場合は記載順に手動で再生できます。

## 構成

|MDX|対象|時間の目安|
|---|---|---:|
|13CAL|TL段差、KC/KF、基準音、出力経路の変化応答|30秒|
|14WAVE|鋸歯状・矩形・三角波のAM/PM、2音域|3分03秒|
|15AMDEP|AMD 0〜127 × AMS 0〜3、AME無効対照|3分32秒|
|16PMDEP|PMD 0〜127 × PMS 0〜7|6分54秒|
|17F80〜24FF0|LFO FREQ 80h〜FFhの全128設定|各3分15秒|
|25F00〜32F70|LFO FREQ 00h〜7Fhの全128設定|合計104分11秒|
|33STATE|保持・再開、同値／異値書き込み、AMD/PMD別ラッチ、キー操作、波形切り替え|2分02秒|
|34CHAN|8チャンネル×4レジスタスロットのAMEと感度|2分12秒|
|35JOINT|AM/PM併用時の別条件検証|1分03秒|
|36CLOCK|3波形で80h〜FFhの各上位桁の下位0/Fを比較|6分28秒|

通常は左が測定音、右が変調しない基準音です。14WAVE・35JOINTでは左にAMとPMを併用する区間があります。34CHANでも測定側を左、基準側を右に保ちます。全チャンネル番号は区間表では1始まり、レジスタスロットは0始まりです。

34CHANはキーONビット順との混同を避けるため測定チャンネルの4スロットを全てキーONし、対象以外のTLを127にしています。TL127を数学的なゼロとは仮定せず、微小残留成分は解析時にノイズ床として扱います。通常音色はALG7、単一キャリア、AR31、DR/SR0、DT1/DT2=0、MUL1、対象TL16です。これによりエンベロープとFM変調の影響を減らします。

## 同梱物

- mdx：再生用MDX。
- schedule：区間の時刻・全レジスタ状態（JSON）、一覧（CSV）。
- traces：公称クロックのレジスタ列。実際のバス書き込み時刻ではありません。
- generate.py / mdx_writer.py：Python標準ライブラリだけの生成器。
- verify.py / coverage.py：MDXの独立デコード、区間・設定網羅性の確認。
- INVESTIGATION_PLAN.md：復元する項目、測定方法、識別できない範囲、独立実装への移行手順。

再生成・検証：

    python generate.py
    python verify.py
    python coverage.py

今回の確認はファイル構造と測定条件の検証です。実機での再生・測定結果はまだ得ていません。
